# Marble demo texture

`marble-texture.jpg` is the original 1K JPEG color map from **Marble 012**, by ambientCG.

- Asset: https://ambientcg.com/a/Marble012
- Download: https://ambientcg.com/get?file=Marble012_1K-JPG.zip
- License: CC0 1.0 Universal; https://docs.ambientcg.com/license/

Only the color map is used. No normal/roughness/displacement maps or texture editor.
This generic marble texture is a visual example, not a verified photograph of a particular supplier's Carrara finish.

In the builder, expand Carrara Marble under Finishes and upload this file.
It will be stored in your configured Supabase bucket, just like an artisan's upload.
The app does not automatically attach it to existing saved products.
