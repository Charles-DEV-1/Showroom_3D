# ShowRoom 3D logo assets

The final mark combines an open showroom frame and an isometric table, using
the site's forest green and sage palette. The website keeps its readable
ShowRoom 3D wordmark beside the image. The earlier chair illustration was
rejected and is not used in the app.

Generated with the built-in imagegen tool on October 8, 2026. No API key or
additional application dependency was needed. Standard image resizing and ICO
encoding produced the smaller assets while preserving transparency.

| File | Use |
| --- | --- |
| `showroom-logo-original.png` | Original generated artwork for presentations and future exports |
| `showroom-logo.png` | 256 x 256 optimized header mark, displayed at 42 x 42 |
| `/favicon-16.png`, `/favicon-32.png` | Small browser-tab PNGs |
| `/favicon.ico` | Browser favicon fallback containing the 32 px PNG |

## Final generation prompt

Use case: logo-brand. Design a refined MINIMAL geometric brand symbol for
ShowRoom 3D, a contemporary web furniture visualization tool. The user rejected
a detailed illustrated chair app badge; do NOT draw a chair, sofa, upholstery,
cushions or wooden legs. Create one bold architectural symbol that combines an
isometric open showroom/room frame and a simple furniture table: an angular
open cube-like room corner made from 3 clean broad forest-green strokes,
enclosing a compact table rendered using just a flat solid parallelogram tabletop
and two simple support strokes. Elegant spatial geometry, coherent isometric
perspective, balanced negative space, refined modern furniture-design studio
identity, custom memorable simple silhouette. Flat two-dimensional vector-style
LOGO, limited to forest green #234B3D with at most one muted sage #91A486 accent.
No 3D render, no photorealism, no gradients, no shadows, no badge, no outlines of
physical objects with fine details, no letters, no numbers, no text, no watermark,
no extra versions, no presentation mockup. Single square composition centered,
symbol occupies 86 percent of canvas, completely transparent background,
genuinely empty transparent negative spaces. Thick clean shapes must remain
readable at 32px browser favicon and 42px website-header size. This is a serious
professional logo mark, not a furniture illustration.
